### Description
This repository contains the code and dataset used in the 
MSc thesis:
"Machine Learning for Product Gain/Loss Prediction: 
A Case Study of PMS and AGO in a Downstream Depot Operations"

### Tools Used
- Python 3
- PostgreSQL
- Power BI
- pgAdmin

### Models Applied
- Linear Regression
- Decision Tree Regressor
- Logistic Regression
- Decision Tree Classifier

### Dataset
730 daily operational records from a West African 
petroleum depot covering PMS and AGO products 
(January — December 2025)
