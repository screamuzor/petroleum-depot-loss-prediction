### Description
This repository contains the code and dataset used in the 
MSc thesis:
"Machine Learning for Product Gain/Loss Prediction: 
A Case Study of PMS and AGO in a Downstream Depot Operations"

### Tools Used
- Python 3
- PostgreSQL
- Power BI
- pgAdmin

### Models Applied
- Linear Regression
- Decision Tree Regressor
- Logistic Regression
- Decision Tree Classifier

### Dataset
4,264 tank-day records and 730 depot-level daily summaries from a West African petroleum depot covering PMS and AGO products across 11 months of 2025 (January — December), sourced from M2 depot summary reports and D2 individual tank daily reports"
